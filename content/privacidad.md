## Qué datos se recogen

Esta web no tiene formularios, registro de usuarios ni herramientas de analítica propias. Solo se tratan datos personales si me escribes voluntariamente por email; en ese caso uso tu dirección y tu mensaje únicamente para responderte, con base en tu consentimiento, y no los cedo a terceros.

## Servicios de terceros

- **Alojamiento:** la web se aloja en GitHub Pages (GitHub, Inc.), que puede registrar datos técnicos de conexión, como la dirección IP, por motivos de seguridad. Consulta la política de privacidad de GitHub.
- **Tipografías:** las fuentes se cargan desde Google Fonts, lo que implica una conexión con servidores de Google.
- **Amazon:** al pulsar un enlace a Amazon sales de esta web y se aplica la política de privacidad de Amazon.
